# FNT Field Reference (Detailed)

Last updated: 2026-03-11

## Container Header (per section)
- `SectionName` (`char[4]`)
- `DataLength` (`be u32`) excluding the section name bytes
- Terminator section: `END ` (no size/data)

## Section Order
1. `FNHD`
2. `BPAL` or `FPAL`
3. `FBMP`
4. `RDAT` (optional)
5. `END `

## FNHD (56 bytes)

| Offset | DataType | Name | Description |
|---|---|---|---|
| 0 | char[32] | Description | Font/source description; may contain multiple null-separated strings |
| 32 | u16 | Unknown_24 | Observed values: 0, 1, 3 |
| 34 | u16 | HasRDAT | 1 when RDAT exists, else 0 |
| 36 | u16 | Unknown_28 | Always 00 |
| 38 | u16 | Unknown_2A | Always 00 |
| 40 | u16 | Unknown_2C | Always 00 |
| 42 | u16 | MaxWidth | Probably max glyph width (usage unclear) |
| 44 | u16 | LineHeight | Line pixel height for text layout |
| 46 | u16 | CharacterStart | First ASCII char in font; observed 20h (space) |
| 48 | u16 | CharacterCount | Number of glyphs |
| 50 | u16 | Unknown_36 | Always 00 |
| 52 | u16 | Unknown_38 | Always 00 |
| 54 | u16 | Unknown_3A | Always 01 |

## BPAL / FPAL (768 bytes)
- 256 RGB entries (triplets).
- Components are 6-bit values (`0..63`), multiply by 4 for 8-bit display.
- Palette index 0 is transparency key.

## FBMP (variable)
Per glyph structure:

| Offset | DataType | Name | Description |
|---|---|---|---|
| 0 | u16 | IsEnabled | 0 disables glyph; >0 enables |
| 2 | s16 | OffsetLeft | Positive shifts right; negative shifts left |
| 4 | s16 | OffsetTop | Positive shifts down; negative shifts up |
| 6 | u16 | Width | Glyph width |
| 8 | u16 | Height | Glyph height |
| 10 | u8[Width*Height] | CharacterData | Indexed bitmap, top-left origin |

Notes:
- Glyph order starts at `CharacterStart` and advances by ASCII code for `CharacterCount` entries.
- Some fonts use sequential `IsEnabled` numbering, others use boolean-like 0/1.

## RDAT (173 bytes, optional)

| Offset | DataType | Name | Description |
|---|---|---|---|
| 0 | char[136] | SourceFile | Source filename/metadata string field |
| 136 | u32 | Unknown_90 | Reported to correlate with FNHD description scan value #1 in some files |
| 140 | u32 | Unknown_94 | Reported to correlate with FNHD description scan value #2 in some files |
| 144 | u32 | Unknown_98 | Always 00 |
| 148 | u32 | Unknown_9C | 2 on ARIALBG, 0 otherwise |
| 152 | u32 | Unknown_A0 | Matches or near MaxWidth in some files |
| 156 | u32 | Unknown_A4 | Matches or near character height in some files |
| 160 | u32 | Unknown_A8 | Observed 1..3 |
| 164 | u32 | Unknown_AC | Observed 1..2 (2 appears on bold ARIAL fonts) |
| 168 | u32 | Unknown_B0 | Always 00 |
| 172 | u8 | Unknown_B4 | Always 00 |

Behavioral note:
- Reference documentation indicates RDAT is unused by runtime; toggling presence did not alter behavior.

## Positioning and Spacing Notes
- Each character allotment: `(Width + 1) x LineHeight`.
- Glyph image is placed within the allotment using `OffsetLeft` and `OffsetTop`.
- Overlap can occur; later-drawn character can visually overdraw earlier one.

### Space character extra width buffer (reported)
- Small fonts (`LineHeight < 16`): `+3`
- Medium fonts (`LineHeight = 16`): `+4`
- Large fonts (`LineHeight > 16`): `+8`
- Note: this extra buffer is not used in console rendering.

## Drop Shadow Notes
- Drop shadow is generated by runtime, not stored in FBMP bitmap.
- Reported process:
  - draw glyph offset by `(+1,+1)`
  - convert non-transparent pixels to near-black with slight transparency
  - place behind original glyph
