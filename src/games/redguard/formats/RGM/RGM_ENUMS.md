# RGM Enumerations (External Reference)

Last updated: 2026-03-08

## ObjectType
- `1`: 3D Object
- `2`: Audio
- `3`: Flat
- `4`: Light Object
- `6`: Light (RGB altering/shadow style)

## AnimType
- `0`: NORMAL_GROUP / animtype_stop
- `1`: COMBAT_GROUP / animtype_no_stop
- `2`: DEATH_GROUP / animtype_no_panic

## FrameType
- `0`: ShowFrame
- `1`: EndAnimation
- `2`: GoToPrevious
- `3`: GoToFuture
- `4`: PlaySound
- `5`: BreakPoint
- `11`: Rumble
- `15`: Transition
